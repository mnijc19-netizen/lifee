# Lifee - 个人职业与全球人生路径决策情报系统 (Personal Career & Global Life Decision Intelligence)

> **全领域最高认知与工程宪法驱动 · 零盲猜与事实铁律架构**  
> 专为大专学历起步、追求高时薪与自由时间、拒绝长工时坐班通勤、追求低成本稳健出国定居路径打造的个人决策情报系统。

---

## 一、这是什么

**Lifee** 不是普通的职业资讯展示网站或 AI 建议 Demo，而是一个**真正用于每天决策的个人情报系统**。

它解决的核心痛点是：
1. **信息孤岛与官方难读**：打破散落在各国移民局、劳工局、行业工会与社区论坛的信息差。
2. **前置死穴排查**：在推荐任何职业或国家前，前置审计硬性门槛（如新西兰电工需 4 年 8000 小时实操且不互认、叉车属于低技能无永居通道、德国机会卡需存入 10 万元限制性账户等）。
3. **破除分析瘫痪**：建立“低后悔投资”清单与 7/14/30 天敏捷验证小实验，结合生存现金流（Runway），告诉用户今天、本周具体应该做什么。
4. **决策闭环**：真实数据 → 结构化 → 交叉验证 → 结合个人真实画像 → 路线对比 → 给出优先级与行动 → 监测政策与市场变化 → 动态更新重评。

## 二、目前已实现的核心系统模块

| 模块 | 核心功能与价值 |
| :--- | :--- |
| **今日决策 (Today)** | 动态呈现当前最重要的 3 件事、当前底层状态矩阵、Top 3 最优路线与破坏力级政策情报 |
| **职业雷达 (Career Radar)** | 严谨映射 ISCO-08 国际职业标准，囊括 AI/3D数字资产、软件、技工、物流、介护等，回答 8 个硬核问题 |
| **国家雷达 (Country Radar)** | 覆盖德、马、日、新、澳、加等国，对比大专友好度、真实工签通道、生活成本与每小时可支配购买力 |
| **路线探索器 (Path Explorer)** | 节点化拆解中国现状到海外长居全流程，标明资金、时间、前置条件与路线失效终止线 (Kill Criteria) |
| **多维对比 (Compare)** | 国家 vs 国家、职业 vs 职业、路线 vs 路线的高密度实机看板，拒绝大段空话，适合一键截图 |
| **情报流 (Intelligence Stream)** | 按个人决策影响分（Impact Score 1-10）倒序排列，呈现最新政策变动的前后事实对比与行动转向建议 |
| **证据库 (Evidence Base)** | 严格划分 Tier A（政府/法律/统计）到 Tier E（真实社区反馈），全部附带原始官方链接与摘录 |
| **我的计划 (My Plan)** | 聚焦 90天/30天/本周/今天，每个任务强制绑定“为什么我现在应该做这个”，内置 7/14/30 天小实验 |
| **生存现金流 (Runway)** | 实时测算房租与生活成本下的极限生存月份，自动拦截资金缺口过大的重资本脱产路线 |
| **低后悔投资 (Low-Regret)** | 提炼 1500→3500 核心英语、AI 3D 自动化管线、Agent 编程脚本与财务纪律，彻底打破害怕选错的焦虑 |
| **AI 决策顾问 & Context 导出** | 纯本地无幻觉 RAG 引擎（六段式推理），支持一键复制完整 Markdown 上下文粘贴至 ChatGPT/Codex/Antigravity |
| **数据健康看板 (Data Health)** | 实时监控 20+ 个官方数据源的抓取与健康度，严格执行合规反爬降级阶梯 (Fallback Ladder) |
| **情报便签导入 (Manual Inbox)** | 支持手动粘贴 URL、帖子、真实个案，解析归档入本地证据库 |

## 三、数据来源与可信度分层 (Source Tier)

系统严格实行 **事实与建议分离**，坚决不制造虚假概率：
- **Tier A (最高权威)**：新西兰移民局 (INZ)、德国联邦技术移民门户 (Make it in Germany)、德国联邦劳工局 (BA)、澳大利亚就业与技能署 (JSA)、加拿大移民部 (IRCC) 与 Job Bank、美国劳工统计局 (BLS) 与 O*NET、日本出入国在留管理厅 (ISA)、新西兰电气工人委员会 (EWRB)、中国国家统计局 (NBS) 等。
- **Tier B (官方教育/机构)**：德国中央外国教育评估处 (ZAB Anabin)、德国歌德学院、IELTS / JLPT 官方考试中心。
- **Tier C (行业与劳动力调研)**：Upwork 全球自由职业经济报告、Glassdoor 全球薪酬数据库。
- **Tier E (社区真实个案与避坑)**：Reddit r/iwantout、r/newzealand、海外华人技工真实社区追踪（专用于排查官方未注明的实际阻力）。

## 四、本地运行与开发

```bash
# 1. 克隆代码
git clone https://github.com/mnijc19-netizen/lifee.git
cd lifee

# 2. 安装依赖
npm install

# 3. 启动本地开发服务
npm run dev

# 4. 执行真实数据采集与汇率更新
npm run collect

# 5. 生产环境打包
npm run build
```

## 五、自动更新机制与部署

- **自动化采集 Pipeline**：通过 `scripts/collector.mjs` 定时拉取开放外汇数据与官方数据源状态，执行 Zod Schema 校验与差异比对，生成最新快照。
- **持续集成与部署**：配置 `.github/workflows/deploy.yml`，在推送到 `main` 分支及每日定时（Cron: 0 2 * * *）自动触发构建并部署至 **GitHub Pages**。

## 六、环境变量配置 (可选 BYOK)

系统 100% 具备本地脱机规则与结构化证据推理引擎，默认无需任何 API Key 即可全功能使用。如需将内置 AI 顾问切换为云端大模型，可在本地创建 `.env` 文件：

```env
# 可选：配置 Gemini 或 OpenAI 兼容端点
VITE_GEMINI_API_KEY=your_key_here
# VITE_OPENAI_API_KEY=your_key_here
# VITE_OPENAI_BASE_URL=https://api.openai.com/v1
```
*注意：`.env` 文件已被 `.gitignore` 严格忽略，绝不上云。*

## 七、数据隐私与已知限制说明

1. **隐私安全**：个人画像与财务数字采用纯 **Local-First (本地优先)** 架构，仅持久化存储在浏览器的 LocalStorage 中。提供 JSON 格式的“导出/导入配置”供用户在电脑和手机之间安全迁移，不依赖外部服务器账户。
2. **已知限制**：
   - 国内部分招聘平台（如 BOSS直聘等）具备高强度反爬与技术保护，系统严格遵守合规原则不实施黑客式破解，对此类平台数据通过人社局宏观统计、大厂公开管线信号及 Manual Evidence Inbox（手动便签导入）进行补充。
   - 签证与移民政策受国际地缘政治影响具有突发性，任何重大决策应以递签当日官方移民局公报为最终准绳。
